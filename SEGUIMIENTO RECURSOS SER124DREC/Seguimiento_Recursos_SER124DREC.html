Registro de Control (Tipo 1)

Identifica a la entidad reportadora y el período. Se diligencia una sola vez por archivo.
El nombre del archivo y el registro de control se arman con estos datos. El número de identificación va sin ceros de relleno en el registro, pero con ceros a la izquierda en el nombre del archivo (lo hace el aplicativo). El ID Recurso se consulta en web.sispro.gov.co → Tablas de referencia → SERIDRecurso. Cada archivo corresponde a un solo ID Recurso.

Cargue masivo desde Excel

Descarga la plantilla, diligénciala y cárgala. Un libro con una hoja por tipo de registro.
La plantilla trae una hoja por cada registro (INCORPORACION, CONTRATOS, POLIZAS, SEGUIMIENTO, REINT_RECURSOS, REINT_RENDIM) más una hoja de INSTRUCCIONES con ejemplos. No cambies los encabezados ni el orden de las columnas. Todo se convierte a MAYÚSCULAS sin tildes al cargar. Las fechas pueden ir como AAAA-MM-DD o como fecha de Excel.

Generar archivo plano y enviar

Valida la estructura, revisa la vista previa y descarga el .TXT.
Completa los datos de la entidad para ver el nombre.
Diligencia los datos para ver la vista previa.
Flujo: diligencia los borradores → Descarga el .TXT → fírmalo y súbelo a PISIS → cuando la validación de PISIS sea exitosa, pulsa Confirmar carga. Los registros quedarán como CARGADO (bloqueados) y ya no se incluirán en archivos posteriores.
Importante: antes de subir el archivo a PISIS debe firmarse digitalmente con un certificado de una entidad certificadora aprobada. Este aplicativo genera el .TXT; la firma se hace aparte.
